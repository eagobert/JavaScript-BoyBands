# JavaScript Boy Bands

An early browser JavaScript exercise from my web development training.

## Practice focus

The files explore arrays, `for` loops, DOM selection, and changing page content with JavaScript. `index.html` loads `boybands.js` and contains example elements for boy bands and vegetables.

## Run locally

Open `index.html` in a browser. There are no dependencies or build steps.

## Status

This is an unfinished learning exercise, preserved as a snapshot of my early JavaScript practice. The arrays are defined, but the loop does **not** render their values to the page. The current code calls `getElementsByClassName()`, which returns a collection, then tries to set `innerHTML` on that collection. The HTML also reuses IDs. It is not a completed app or a demonstration of production code.
